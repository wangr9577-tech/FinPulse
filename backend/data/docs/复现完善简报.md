# “择时六面图”复现完善简报

基准研报：国盛证券《择时六面图：流动性上行、景气度下行》（2022-07-31）  
本次复核截面：2022-07-31；最新数据统一截面：2026-07-24

## 一、结论

原复现具备可运行框架，但不能称为“完整、严格复刻”。主要问题是：部分月度数据把统计期末当成可得日；信贷脉冲曾使用全样本季调和双向插值；DR007代理与SHIBOR高度重复；基金季度仓位曾在报告期末提前使用；35项复核缺少库存周期、A股景气度并合并了新高/新低；“最新信号”混用不同年份的数据；爬虫总控遗漏DR007且会在内部失败时仍显示完成。

完善后，程序可以称为“无明显未来函数、边界明确的公开数据复现”。它仍不是券商内部模型的完全复刻，原因是部分原始数据、模型参数、主观缓冲区及六维聚合权重没有披露。

自动质量检查已全部通过。2022年时点复核共35项：

- 方向一致20项；
- 方向不一致5项；
- 因数据/模型/口径不足而不作比较10项；
- 在25项可比较指标中，方向一致率为80%，但其中含透明代理，不能解释为样本外预测准确率。

五项不一致为：信贷脉冲、PE_TTM中位数、PB、融资融券余额、偏股基金仓位。主要原因分别是季调方法差异、Wind与公开数据口径差异、研报“接近阈值”的主观缓冲未披露，以及代理趋势算法/底层数据不同。

## 二、本次完善内容

1. 月度宏观数据保留“统计期”和“保守可用日”两个日期。一般月度数据假设次月20日可用，发/用电量次月25日，开户数次月30日，基金季报为报告期末后45日；所有信号从下一交易日生效。
2. 信贷脉冲改为逐期递归STL：计算历史任一点时，只拟合截至该点的数据；缺口仅前向填充，取消双向插值。
3. M2-GDP在M2或GDP任一数据发布时重算，并只使用该时点已经公布的最新值。
4. DR007明确降级为水平代理。原式所需的7天逆回购政策利率历史缺失，且2022年前代理序列基本为SHIBOR加固定利差，因此不与SHIBOR重复计分。
5. 基金仓位改为披露后生效；深沪两融合计要求两个市场数值同时存在。
6. 新高占比和新低占比分开列示，复核表和最新汇总均为35项。
7. 最新汇总增加统一`as_of_date`、`effective_date`、数据龄、过期标志、是否可聚合及当前可用分数。日/月/低频数据分别采用10/75/180天的过期阈值。
8. 增加一键运行和自动质量检查；爬虫补跑DR007，检查输出是否在本次运行中真实刷新，并把全空占位文件判为失败。

## 三、统一公式与信号编码

设：

- \(\mathrm{MA}_n(x_t)=\frac{1}{n}\sum_{i=0}^{n-1}x_{t-i}\)；
- \(Q_{p,t-1}(x)\)为只使用 \(t-1\) 期及以前数据计算的历史 \(p\) 分位数；
- \(Z_{n,t}(x)=\frac{x_t-\overline{x}_{n,t}}{s_{n,t}}\)；
- 信号分数：`+1=看多`、`0=中性/未触发`、`-1=看空`、空值=不可计算或方向未披露。

日度收盘信号在下一交易日生效。月度/季度信号先等数据可用，再映射到下一交易日。

## 五、最新截面如何解释

截至2026-07-24，35项中只有9项同时满足“规则较明确、数据未过期、允许聚合”：

| 指标 | 当前分数 |

这些分数的简单和为+1，但这不是研报的六维总分。研报没有披露35项到六个维度的权重、半分/接近阈值规则及最终缩放方法，因此程序不伪造“官方[-5,5]总分”或雷达图。

## 六、使用建议

运行 `python run_all.py`，程序将依次执行清洗、指标计算和质量检查。以 `results/最新信号汇总.csv`、`results/研报2022时点复核.csv` 与 `results/质量检查汇总.json` 为准。

若要进一步接近原研报，优先补齐四类数据：真实发布日期；DR007与7天逆回购政策利率；全市场个股新高/新低及行业收益面板；期权CPR/SKEW和主动权益基金日频仓位。未取得这些输入前，不应把代理结果用于宣称完整复刻或直接投资决策。
