# 📚 盘前买方启发式规则手册 (Premarket Heuristics Reference Manual)

本文档整理自顶级买方基金经理与盘前博主的实战经验，为 Extractor Agent、Analyst Agent 及 Synthesizer Agent 提供定性与定量推演的买方沉淀规则。

---

## 一、 公司级事件“真金白银”审计规则表

| 事件类型 | 触发条件与特征 | 买方评级 | 归因 rationale | 研报处理规则 |
| :--- | :--- | :--- | :--- | :--- |
| **注销式回购** | 公告明确指出回购股份用于“注销注册资本” | **[特大利好]** | 真实减少总股本 $N$，增厚单股 EPS，无未来抛售稀释隐患 | 生成独立新闻条目，列入板块整体结论第一条 |
| **激励式回购** | 回购用于“员工持股计划”或“股权激励” | **[中性]** | 不减少总股本，行权后可能产生市场抛压 | 仅作为常规事件列出，不得评为重大利好 |
| **Q2 环比加速** | Q2 单季营收/净利润环比 QoQ 增长 > 30% | **[强看多]** | 证明基本面斜率向上，需求正处于加速交付期 | 在【整体结论】中强调基本面加速形态 |
| **单纯同比高增** | YoY 增长高但 Q2 环比持平或下滑 | **[中性/谨防高开低走]** | 多为去年同期低基数导致的幻觉 | 在【关键事件】中提示环比放缓风险 |
| **跨年度重大订单** | 订单合同金额占上一年度营收 > 15% 且跨期 2 年以上 | **[中线看多]** | 锁定中长期业绩基底，抗宏观波动能力强 | 提炼订单金额与营收占比数据放入关键事件 |
| **高管自筹增持** | 董事长/高管二级市场自筹资金增持 | **[看多]** | 内部人真金白银表态，提供坚实的估值安全边际 | 列为情绪修复催化剂 |

## 二、 跨市场与产业链传导映射表 (Cross-Market Transmission)

### 1. 美股 -> A股 传导路径
- **路径 A (AI 算力与硬件)**：
  - *触发信号*：微软 / 谷歌 / 亚马逊 / Meta 上调云计算 Capex 资本支出指引。
  - *映射板块*：国内 CPO / NPO 光模块（中际旭创、新易盛）、交换机、算力服务器（工业富联）。
  - *推演逻辑*：海外巨头基础设施扩容直接转化为国内光模块龙头的高毛利订单。
- **路径 B (AI 下游应用与软件)**：
  - *触发信号*：苹果/微软发布杀手级 Agent（如桌面 Agent、WorkBuddy）。
  - *映射板块*：国内办公软件（金山办公）、AI 智能体应用、Token 工厂基础设施（润建股份）。

### 2. 日韩 -> A股 传导路径
- **路径 A (存储芯片)**：
  - *触发信号*：韩国海力士 / 三星 / 威刚表态全球存储紧缺，签订 long-term 大单。
  - *映射板块*：A 股存储龙头（兆易创新、百维存储、江波龙）。
- **路径 B (被动元件 MLCC)**：
  - *触发信号*：三星电机 / 太阳诱电统一发布涨价函（出货价格上调 30%）。
  - *映射板块*：A 股电子元器件与 MLCC 龙头（三环集团、风华高科）。

## 三、 资金底线与“三个收敛”策略评估框架

### 1. 资金托底线评估 (Capital Floor Audit)
- **ETF 净流入指标**：若宽基 ETF（如沪深 300 ETF、上证 50 ETF）出现连续 5 个交易日以上净流入，或单日净流入超 500 亿元：
  - *策略判定*：确定为官方“资金底”建立，极小概率破位下行。
  - *支撑区间*：如 3800 点关键心理防线。

### 2. “三个收敛”配置框架 (Three Convergences Framework)
```text
┌────────────────────────────────────────────────────────┐
```

## 四、 研报冲突消解矩阵 (Conflict Resolution Matrix)

当【量化择时信号】与【行业资讯情绪】产生矛盾时，Synthesizer CIO 节点必须采用以下买方归因矩阵进行消解：

| 矛盾类型 | 表现形态 | 买方归因解释 (Rationale) | 策略结论 |
| :--- | :--- | :--- | :--- |
| **冲突 1** | 流动性指标偏紧，但科技板块资讯强看多 | 流动性指标反映全市场总量资金，而科技板块受独立产业周期与 Capex 驱动，呈现结构性虹吸效应 | 维持科技核心标的配置，不盲目看空 |
| **冲突 2** | ERP 估值极具性价比，但新闻舆情整体悲观 | ERP 处于历史高分位表明悲观情绪已充分计价，绝对估值具备安全边际，属于典型的“情绪末端与政策底重合” | 建议分批逢低布局，强调高抛低吸 |
| **冲突 3** | 硬件板块业绩炸裂，但美股半导体板块出现挤泡沫大跌 | 上游硬件经历了短期估值过快扩张，市场正在验证下游变现能力，属于典型的“业绩兑现期的估值再平衡” | 避免盲目追高，关注回调后的错杀反弹 |

## 五、 金融研报排版与去 Emoji 规范

1. **绝对禁令**：严禁在研报标题、正文、列表、总结论中出现任何 Unicode Emoji 符号（如 🚀, 📈, ⚠️, ❌, ✅）。
2. **替换规范**：
   - 风险警示采用 `[风险警示]`
   - 逻辑传导链采用 `[传导链条]`
   - 看多情绪采用 `[看多]`
   - 看空情绪采用 `[看空]`
   - 中性情绪采用 `[中性]`
3. **分行规范**：标题 `#### 【整体结论】` 与后续正文之间、各段落之间必须使用双换行 `\n\n` 隔离，确保无头浏览器 Playwright 编译为 PDF 时排版清晰美观。
