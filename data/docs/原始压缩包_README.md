# 择时六面图复刻 — 数据爬取项目

## 来源
- 研报：国盛证券《择时六面图：流动性上行、景气度下行》（2022-07-31）
- 工作手册：`择时六面图复刻_数据获取与整理工作手册_无Wind版`

## 目录结构
```
研报数据爬取/
├── raw/                    # 原始数据（按来源分类）
│   ├── chinamoney/         # 中国货币网
│   ├── pbc/                # 中国人民银行
│   ├── nbs/                # 国家统计局
│   ├── csindex/            # 中证指数
│   ├── sse/                # 上交所
│   ├── szse/               # 深交所
│   ├── chinaclear/         # 中国结算
│   ├── market/             # 市场行情
│   └── forum/              # 股吧文本
├── processed/              # 处理后的35项指标
│   ├── liquidity/          # 货币/信用 (指标1-6)
│   ├── macro/              # 宏观经济 (指标7-12)
│   ├── valuation/          # 估值 (指标13-18)
│   ├── flow/               # 资金面 (指标19-21)
│   ├── technical/          # 技术指标 (指标22-28)
│   ├── breadth/            # 市场广度
│   ├── sentiment/          # 情绪 (指标29-32)
│   └── options/            # 期权 (指标33-35)
├── scripts/                # 爬取和处理脚本
├── metadata/               # 元数据文档
├── logs/                   # 运行日志
└── README.md
```

## 运行方式

### 全部运行
```bash
cd scripts
python run_all.py
```

### 按组运行
```bash
cd scripts
python fetch_liquidity_credit.py   # A组: 货币/信用
python fetch_nbs_macro.py          # B组: 宏观经济
python fetch_valuation.py          # C组: 估值
python fetch_capital_flow.py       # D组: 资金流向
python fetch_market_technical.py   # E组: 技术指标
python fetch_sentiment.py          # F组: 情绪
python fetch_options.py            # G组: 期权
```

## 数据源优先级
